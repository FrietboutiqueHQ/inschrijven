# Inschrijfformulier Frietboutique

Online versie van het inschrijfformulier voor nieuwe medewerkers: https://frietboutiquehq.github.io/inschrijven/

Ingevulde gegevens worden niet online opgeslagen of verstuurd. De medewerker slaat ze op als bestand en mailt dat naar priscilla@frietboutique.nl. Dat bestand wordt ingelezen in de contractgenerator (privé-repository `contractgenerator`).

Bron: `Inschrijfformulier.html` uit de contractgenerator. Na een wijziging daar ook `index.html` hier vervangen.
